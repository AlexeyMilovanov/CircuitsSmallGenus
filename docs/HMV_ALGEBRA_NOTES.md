# HMV algebra for the E2 leaf `letterWordACC_impl` — source content and soundness analysis

Date: 2026-08-16.  Source: Hansen–Miltersen–Vinay, *Circuits on Cylinders*, ECCC TR02-066
(stored as `docs/hmv-circuits-on-cylinders-TR02-066.pdf`).  This note records (a) the exact
algebraic statements of the paper that E2 must port, and (b) a soundness analysis of the
assembly sketch used in pipeline iterations 11–14, which found a gap.

## 1. What the paper actually proves (and what it does NOT)

Theorem 2 (upper bound): every constant-width poly-size cylindrical circuit is in ACC^0.
The proof reduces the circuit value problem CV_k, by an AC^0 reduction, to the word problem
of the finite monoid `N̂_k` (functions {0,1}^k → {0,1}^k computed by width-k cylindrical
circuits with constant inputs allowed in first and last layers), then proves:

* **Lemma 7**: constants in all layers stay within `N̂_k`.
* **Proposition 8**: every group in `N̂_k` is isomorphic to a group in `N_k`
  (no constant output nodes).  Proof: the constant output-node set is common to the whole
  group (feed `0^k`/`1^k` through `C₁' ∘ C₁ ∘ C₂` computing g); replace constant outputs by
  COPY-from-below to build an injective monoid hom into `N_k`.
* **Lemma 9**: identify a vector `x ∈ {0,1}^k \ {0^k,1^k}` with its set of maximal cyclic
  1-intervals.  `f ∈ N_k` maps an m-interval vector to at most m intervals; if exactly m,
  then `f(x) = { f(I) | I ∈ x }` (intervals map interval-wise).
* **Lemma 10** (the non-crossing core): if `f ∈ N_k` maps an antichain of intervals
  `[a_i,b_i]` (cyclically ordered) to `[c_{π(i)}, d_{π(i)}]`, then π lies in the cyclic
  group generated by the full cycle `(1 2 … m)`.  Proof: depth-1 circuit arcs from
  `[a_i,b_i] \ [a_{i+1},b_{i+1}]` to `[c_{π(i)},d_{π(i)}] \ [c_{π(i)+1},d_{π(i)+1}]` must
  exist, and cylindricality forbids crossings.
* **Lemma 11**: the "in between" relation on intervals is preserved by `f`.
* **Lemma 12**: a permutation of `S ⊆ Im e` restricts to a permutation of `min(S)`.
* **Proposition 13**: **all groups in `N_k` are cyclic.**  Proof: for a group `G` with
  identity `e`, let `I` = intervals of `Im e`; decompose `I` into antichain layers
  `I_j = min(I \ ⋃_{i<j} I_i)`; by L12+induction each `f ∈ G` permutes each `I_j`, by L10
  as a cyclic shift; by L11 (betweenness) the action on `I_1` determines everything; hence
  `G` embeds in a cyclic rotation group.
* (Section 4, branching-program variant: **Proposition 6** proves the same cyclicity for
  the *relation* monoid `M_k` directly, with the R-set / π_A machinery.)

**Crucially, that is all the algebra the paper contains.**  For the circuit-complexity
step it then simply cites Barrington–Thérien [4]: *the word problem of a solvable finite
monoid is in ACC^0* (JACM 35(4), 1988).  So the true content of our remaining Lean leaf

```
letterWordACC_impl (w) : LetterWordACC w
```

is: **(E2-b)** the HMV cyclicity results above, ported to `NonCrossing w` (our `N_k`), plus
**(E2-c)** a quantitative Barrington–Thérien upper bound for the fixed monoid
`NonCrossing w` (cyclic subgroups ⇒ solvable), in the letter-recognizer form of
`LetterWordACC`.  HMV give no proof of (E2-c); it must be formalized from BT or an
equivalent route.

## 2. Soundness gap in the iteration-11/14 assembly sketch ("Leaf 3")

The sketch was: guess the ≤ 2^w R-descent boundaries of the prefix products, recognize each
descent-free block by a MOD-count of cyclic shift amounts (Schützenberger-group cyclicity),
assemble with `accOrAnd`.  Two problems, found 2026-08-16:

1. **Rank-1 collapse (fatal as stated).**  Rank-1 elements (constant maps; e.g. literal
   layers) form a single R-class with total kernel.  A word may sit at rank 1 from the
   first letter on; then there are no descents, the "block" is the whole word, and the
   within-block subproblem *is* the full point-trajectory problem `c_{t+1} = u_t(c_t)` —
   exactly the original circuit-value problem.  The Schützenberger groupoid of the rank-1
   class is trivial and carries no information, so per-block MOD counting proves nothing
   there.  Any sound route must handle low-rank dynamics through the ideal/wreath
   structure of `NonCrossing w` itself (as BT do), not through prefix R-blocks alone.

2. **Moving-basepoint dependence (already flagged in the plan doc).**  Within a
   descent-free block the per-letter rotation amount is measured against the *current*
   range set `S_{t-1} = range(prefixEnd t-1)`, which is input-dependent; computing it for
   every position is itself a prefix-evaluation problem.  The width-2 example
   `A(x₁,x₂) = (x₁, x₁∨x₂)` with alternating swaps shows ranges genuinely move at constant
   rank.  So shift amounts are not directly MOD-summable without first solving a prefix
   problem at a lower level — this is precisely the wreath-product structure of the BT
   induction, and it cannot be skipped.

Positive structural facts that survive and should be reused:

* `letterWordACC_zero` and `letterWordACC_units` are proved and genuinely useful (the
  units case is the top group layer of any cascade).
* **Comparability monotonicity** (new, 2026-08-16): a monotone map that is injective on a
  set can only *add* comparabilities between images; it can never remove them.  Hence
  along any descent-free block the comparability relation of the range set is
  non-decreasing, so it changes at ≤ r² positions, and between changes every step is an
  order-isomorphism of the induced posets.  This is a candidate aperiodic "shape" layer
  for an explicit cascade (below), but it is a *proposal*, not a verified normal form.

## 3. Recommended route for E2-c (in order of preference)

0. **Adversarial computational validation first** (plan doc's research-pivot rule): before
   any large Lean development, enumerate the depth-1 non-crossing layer maps for w = 3, 4,
   close under composition, and machine-check: (i) all subgroups cyclic (HMV P13 — should
   pass, it is proved); (ii) the key finite-semigroup statement of whichever E2-c route is
   chosen, stated exactly.  Any route whose normal form fails at w ≤ 4 is dead.
1. **Faithful BT induction** for the fixed monoid `M = NonCrossing w`: prefix evaluation
   by a constant-length cascade — an aperiodic/R-trivial layer (evaluable in AC^0 by
   guess-and-verify of the ≤ const change positions) feeding cyclic-group layers (MOD
   counts, `accCountEq`/`accModIn`/`accModulusLift`), iterated ≤ const times.  The HMV
   interval/antichain hierarchy (`I_j` layers, cyclic shifts on antichains, betweenness)
   is the natural source of the explicit cascade coordinates; comparability monotonicity
   supplies aperiodicity of the shape coordinate.  All ACC gadgets are already proved.
2. Factorization forests (Simon) with explicit quantitative depth for a fixed monoid, if a
   clean Lean route to Ramseyan splits appears.
3. Generic Krohn–Rhodes + BCST aperiodic word problem: faithful but far more expensive;
   last resort.

The final theorem shape stays `LetterWordACC w` — modulus/depth/exponent may depend on `w`
arbitrarily, so constant-in-`w` cascades of length ≤ f(w) and guess sets of size
`len^{g(w)}` are all admissible.

## 4. Experimental confirmation of the cascade heart (2026-08-17)

Scripts: `docs/experiments/localized_cyclicity.py`, `docs/experiments/holonomy_groups.py`
(also at `~/oq3-experiments/` on the VM).  Both enumerate the full monoid
`NonCrossing w` from depth-1 non-crossing layer maps (w=2: 34 elements; w=3: 3844
elements — a more generous generator convention than iter-15's 3322; all conclusions
below hold for the larger monoid, hence a fortiori robust).

**Experiment 1 — localized cyclicity: PASSED (strong form).**  For w=2 and w=3, for
EVERY subset `S ⊆ Config w` (all 2^{2^w}−1 of them, not merely the reachable ones),
the group `G_S = { m|_S : m ∈ NonCrossing w, m(S) = S }` of realized permutations
of `S` is cyclic.  Orders observed: ≤ w (e.g. w=3: order 3 on the full cube = the
shift group; order 2 on fifteen 4-element sets — the alternating-range examples;
trivial otherwise).

**Experiment 2 — holonomy-group cyclicity: PASSED.**  For every reachable `S`
(closure of `{Q}` under the monoid) with brick family `bricks(S)` = maximal proper
reachable subsets of `S`: the group of permutations of `bricks(S)` induced by
monoid elements that permute the brick family setwise (V1: any such `m`; V2: only
`m` bijective on `S`) is cyclic.  Orders ≤ 3.  This is the group form that a
holonomy/wreath (Eilenberg ch. XII / Zeiger) decomposition of the action
`(NonCrossing w, Config w)` actually needs — single-subset cyclicity does not
formally imply it, so it needed its own check.

**Consequences for the route.**
* The two heart lemmas to formalize (statements now pinned, computationally
  validated at w ≤ 3):
  - (H1) for every `S : Finset (Config w)`, the setwise-stabilizer restriction
    group `G_S` inside `NonCrossing w` is cyclic;
  - (H2) the brick-family version: elements permuting a family of pairwise
    disjoint-or-nested reachable subsets induce a cyclic permutation group of
    the family.
  Proof plan for both = localized HMV Prop 13: min-antichain preservation (L12
  analogue), interval structure (`ConfigInterval`, `GeneratorGeometry` bricks
  already proved), rotation matching for generators (L10 analogue from the
  incidence certificate), betweenness determinacy (L11 analogue), then closure
  under composition.
* The remaining open DESIGN item is the assembly: a holonomy-style triangular
  cascade for the action `(NonCrossing w, Config w)` feeding
  `cascade_cyclic_layer` (groups — cyclic by H1/H2) and aperiodic layers.
  WARNING for the aperiodic part: `cascade_aperiodic_layer` accepts only
  BOUNDED-CHANGE coordinates; generic holonomy aperiodic layers are not
  bounded-change (rank-1 point trajectories under literal resets flip
  unboundedly often).  Either derive the holonomy aperiodic coordinates in
  bounded-change form (per level: "which descent/brick-collapse epoch", which IS
  bounded by the lattice height), or add a last-reset/R-trivial evaluation
  gadget.  Do not regress to prefix-R-block-only schemes (rank-1 refutation
  stands).
