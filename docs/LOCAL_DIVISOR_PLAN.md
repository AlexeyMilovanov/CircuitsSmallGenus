## 1. The local divisor (already formalized — reference)

For `c : M`, `LocalDivisor c` is the subtype `{x // (∃ y, x = c*y) ∧ (∃ y, x = y*c)}`
with `(x̃*c) ∘ (c*ỹ) = x̃*c*ỹ`, unit `c`.  Formalized in `LocalDivisor.lean` with the
two workhorse lemmas

```
localDivisor_mul_val  : p.val = x * c → (p * q).val = x * q.val
localDivisor_mul_val' : q.val = c * y → (p * q).val = p.val * y
```

`card_localDivisor_lt : ¬IsUnit c → card < card M` (via: `c*y = 1` in a finite monoid
forces `IsUnit c` — left multiplication is surjective hence injective).
`localDivisorDom c : Submonoid M` is `{x | ∃ y, c*x = y*c}`, and
`localDivisorHom : localDivisorDom c →* LocalDivisor c`, `x ↦ c*x`, is a surjective
monoid hom — so `LocalDivisor c` is a divisor of `M`.

## 2. S1: groups lift through surjections (paper proof to transcribe)

Statement: `φ : N →* M'` surjective between finite monoids, `LocalUnitsCommute N` →
`LocalUnitsCommute M'`.

Unfold the target: given `e a a' b b'` in `M'` with `e*e = e`, `a,a'` mutually inverse
local units at `e`, same for `b,b'`, show `a*b = b*a`.  Let `H` be the subgroup
`{e, a, b, ...}` — formally, one does NOT need to construct `H`; it suffices to lift
the five elements coherently:

1. `U := φ⁻¹ ({x | x ∈ M', x is in the subgroup generated by a,b at e})` is unwieldy;
   instead lift the whole local group: let `T' := {g : M' | e*g = g ∧ g*e = g ∧
   ∃ g', e*g' = g' ∧ g'*e = g' ∧ g*g' = e ∧ g'*g = e}` (the unit group of `e M' e`).
   `a, b ∈ T'`.  Put `U := φ⁻¹ T'` — a nonempty (φ surjective) subSEMIgroup of `N`
   (products of local units at `e` are local units at `e`).
2. Pick `z₀ ∈ U` minimizing the cardinality of the finite set
   `I := image of (fun (p : N × N) => p.1 * z₀ * p.2)` over `U¹ × U¹` (with formal
   identities, i.e. `I = {z₀} ∪ z₀U ∪ Uz₀ ∪ Uz₀U`).  Then `I` is a minimal ideal of
   `U`: it is an ideal, and for any `z ∈ I`, `U¹zU¹ ⊆ I` is an ideal contained in `I`,
   nonempty, hence by minimality of the chosen cardinality `U¹zU¹ = I`.  (This
   Finset-cardinality argument replaces abstract minimal-ideal theory; use
   `Set.Finite`/`Finset.min'` on the image cardinalities.)
3. Idempotent: any finite semigroup element has an idempotent power
   (`∃ k > 0, x^k * x^k = x^k` — pigeonhole `x^i = x^j`, then `x^{k}` with
   `k ≡ 0 (mod j−i)`, `k ≥ i`).  Take `f := z^k ∈ I` idempotent (`I` closed under
   products of its elements with themselves since it is an ideal of `U` and `z ∈ U`).
4. `φ f` is an idempotent of `T'`-closure... precisely: `φ` maps `U` into `T'`, and the
   only idempotent in the group `T'` (identity `e`) is `e`; hence `φ f = e`.
5. `fIf` (with the original multiplication of `N`) is a group with identity `f`:
   for `z ∈ fIf`, `U¹zU¹ = I` gives `f = azb`; set `A := f*a*f`, `B := f*b*f`; then
   using `f*z = z = z*f`:  `A*z*B = f`.  In the finite monoid `f U¹ f`, a one-sided
   inverse is two-sided (same surjective/injective argument as in
   `card_localDivisor_lt`), so `A*z` is a unit, hence `A` and `z` are units of
   `f U¹ f`, and `z⁻¹ = B*A ∈ fIf` because `f ∈ I` and `I` is an ideal.
6. Surjectivity: `φ(I)` is an ideal of the group `T'`... formally: for every `t ∈ T'`
   there is `y ∈ I` with `φ y = t`: pick any `u ∈ U` with `φ u = t` (surjectivity),
   any `z ∈ I`; then `y := f * u' ...` — cleanest: `φ(I) ⊆ T'` is an ideal of the
   group of units of `eM'e`, nonempty, hence equals it (in a group, `h = (h·g⁻¹)·g`
   shows any nonempty ideal is everything).  So choose `ya, yb ∈ fIf` with
   `φ (f*ya*f) = a`, `φ (f*yb*f) = b` — both lie in the GROUP `fIf`.
7. Apply `LocalUnitsCommute N` with `e := f`, `a := f*ya*f` and its group inverse in
   `fIf`, `b := f*yb*f` likewise: all thirteen equations hold in `fIf` by the group
   structure.  Conclude they commute in `N`; apply `φ`: `a*b = b*a` in `M'`. ∎

Everything is elementary; the only infrastructure to build is the idempotent-power
lemma and the cardinality-minimal-ideal device.  Expect 300–600 lines.  After S1,
`localUnitsCommute_localDivisor` in `LocalDivisor.lean` becomes fully proved
(it is already written as `S1 ∘ θ-surjectivity ∘ submonoid-transport`).

## 3. S2: the marked compression lemma (circuit construction)

Statement (`LocalDivisorCompression.lean`): for a finite monoid `M`, `c : M`,
`B : Set M`, given `MonoidWordACCGen ↥(Submonoid.closure B)` and
`MonoidWordACCGen (LocalDivisor c)`, conclude
`MonoidWordACCGenOn M (insert c (Submonoid.closure B : Set M))` — the generalized
interface restricted to words whose letters provably lie in `closure B ∪ {c}`.

Algebraic identity (prove first, pure algebra, no circuits):
for a word `w = u₀ c u₁ c … c u_k` (each `u_i` a product of `closure B` elements),

```
prod w = u₀ * ((c u₁ c) ∘ (c u₂ c) ∘ … ∘ (c u_{k−1} c)).val * u_k
```

where `∘` is the `LocalDivisor c` product and the empty middle product is the unit
`c`.  Formalize on `List M` with a `blockProd`-compatible phrasing; the telescoping is
`localDivisor_mul_val'` applied `k−2` times.

Circuit construction, per requested block `(a, b)` — **block-local, this is the key
soundness point**:

* Positions of `c` inside `[start+a, start+b)` only.  A derived `LocalDivisor c`-valued
  word `v` of the same length: at a position `t` holding `c` whose NEXT `c` inside the
  block is `s`, the letter is `⟨c * (gap product) * c, _⟩`; at every other position the
  letter is the unit `c`.  NEVER consult positions outside the requested block: a `c`
  just beyond the right endpoint changes the answer (counterexample: Rees quotient of
  `{a,c}*` by words of length ≥ 3; ambient word `cac`, sub-block `ca`).  The
  generalized interface allows a different derived word for every `(a, b)` — use that.
* Derived-letter recognizers (`v_t = q`): OR over (1) `letter t ≠ c` and `q = c`;
  (2) `letter t = c`, no later `c` in the block, `q = c`; (3) guessed `s`, guessed
  `u ∈ ↥(closure B)`: `letter t = c ∧ letter s = c ∧ (∀ strictly between: ≠ c) ∧
  (N-block-product of (t, s) = u) ∧ c*u*c = q`.  For the N-product, map letters by
  `c ↦ 1` (recognizer: `letter i = n ∨ (n = 1 ∧ letter i = c)`) and invoke the
  recursive `MonoidWordACCGen N` circuits; the no-`c`-between conjunction makes the
  mapped product the true gap product.  `O(len·|N|)` disjuncts per letter.
* Invoke `MonoidWordACCGen (LocalDivisor c)` on the derived word, with input depth =
  the depth of the derived-letter recognizers (this is exactly why the Gen interface
  exists: plain depth-2 letter recognizers cannot absorb the recursion) and input
  modulus = the modulus `m_N` returned by the `N` call (Gen guarantees `m_N ∣ m_c`).
* Final assembly for `prod = g`: OR of (i) no `c` in the block ∧ N-product of the whole
  (mapped) block = g; (ii) guessed first/last `c` positions `p ≤ r`, guessed
  `u₀, u_k ∈ N`, `h ∈ LocalDivisor c` with `u₀ * h.val * u_k = g`, verifying
  first/last-ness by unbounded conjunctions, the prefix/suffix N-products, and the
  derived-word `M_c` product over the whole block.  `O(len²)` boundary guesses ×
  constantly many algebraic values.
* Soundness holds for EVERY `(a,b,g,x)` (each branch verifies its factorization);
  completeness only for `a ≤ b ≤ len` (actual boundaries and products); for `a > b` or
  `b > len` use the constantly-false circuit — same discipline as `RTrivialWordACC`.
* Bookkeeping: sizes are polynomial in `size + len + 2` with exponent depending only on
  the fixed monoids; depth adds a constant per level.  Reuse `exists_acc_orPair` /
  `assemble_size_bound` / `const_mul_pow_le_pow` and the modulus-lifting lemmas that
  `MonoidWordACCGen.lean`'s closure proofs already use.

Decomposition advice: split into (a) the algebraic factorization lemma; (b) a
`derivedLetter` definition + its recognizer lemma; (c) the final assembly.  Expect
1000–2000 lines total; the guess-and-verify patterns match `EpochReduction.lean` and
`RTrivialWordACC.lean` closely — copy their shapes.

## 5. S4: the induction

LocalUnitsCommute M → MonoidWordACCGen M`, by strong induction on `Fintype.card M`
(pattern: `∀ n, ∀ M [..], Fintype.card M ≤ n → …`, recursing at the two smaller types).

* Generating set: choose `A : Finset M` with `Submonoid.closure ↑A = ⊤` of MINIMAL

* If every member of `A` is a unit: every element of `M` is a unit

### 6a. Constant-free generators and their closure (`ConstantFreeLayers.lean`)

A certified layer (`isNonCrossingMap` witness) is *constant-free* when every gate of
the (ell+1)-layer is a computation gate (`andGate`/`orGate`) with ≥ 1 layer-ell
predecessor — no `literal` kinds, no empty predecessor sets.  Define
`isConstantFreeMap w f` by strengthening `isNonCrossingMap` accordingly and
`NonCrossingCF w := Submonoid.closure {f | isConstantFreeMap w f}` — a submonoid of
`NonCrossing w` (each constant-free layer is in particular certified).
Prove the two basic semantic facts, first per generator (direct from `layerTransMap`:
an AND/OR over a nonempty set of predecessors), then by closure induction:
`runTrans m ⊥ = ⊥` and `runTrans m ⊤ = ⊤` for `m ∈ NonCrossingCF w`
(`⊥ = fun _ => false`, `⊤ = fun _ => true`), plus monotonicity (restriction of the
existing `monotone_of_mem_nonCrossing`).

componentMap_eq   : m ∈ NonCrossingCF w → intervalCount (runTrans m x) = intervalCount x →

### 6c. The antichain rotation lemma (`RotationLemma.lean`) — HMV Lemma 10

```
rotation_of_antichain : m ∈ NonCrossingCF w →
  (L L' : Finset (Config w)) antichains of proper interval configs, listed by
  canonical start (IntervalStart.startOf), runTrans m mapping L bijectively to L' →
  the induced permutation is a cyclic shift of the start orders
```

Single-generator core: `P(I)` (arcs from the interval `I`) is a nonempty proper
interval of the arc word (empty ⟹ output ⊥; full ⟹ output ⊤ — both excluded by
properness of the output); the `P(I_r)` form an antichain AT THE ARC LEVEL (inclusion
of arc sets forces inclusion of outputs by gate monotonicity — do NOT argue via
inclusion of the `I_r` themselves); the leading cut of `P(I)` determines the start of
the output interval via the first-true-target function λ (case analysis: cut inside an
OR block ⟹ that target; inside an AND block ⟹ next block, which is true unless it is
a trailing partial AND — excluded because the output is nonempty); both
`start ↦ leading cut of P(I)` and λ are weakly-cyclic-order-preserving degree-one
maps, and distinct proper intervals in an antichain have distinct starts
(`IntervalStart.startOf_ne_of_incomparable`), so the composite is strictly
order-preserving on the family ⟹ rotation.  Word extension: intermediate images of
the `1_{I_r}` stay nonempty proper intervals (endpoint-fixing from 6a excludes
`⊥`/`⊤`; the component lemma keeps `ρ = 1`), stay distinct (final images distinct)
and stay antichains (a monotone suffix cannot un-nest a nested pair into distinct
incomparable outputs); rotations compose.  Expect 1000–2000 lines; the λ case
analysis is the fiddliest piece of the whole plan — formalize "cuts" as positions in
the arc word (indices into the list) and "degree one" concretely as: the map on cut
positions is monotone on one full traversal and returns to its start after one lap.

### 6e. Constant elimination (`ConstantElimination.lean`) — the new trick

Given `e a a' b b'` in `NonCrossing w` (constants allowed) with the equations, let
`X := Fix (runTrans e)`, `K :=` coordinates constant across `X` (with values `κ`),
`J :=` the rest.  If `J = ∅` then `X` is a singleton and everything commutes
trivially.  Otherwise build TWO explicit certified single layers:

* `A_layer`: literal `κ_i` at each `i ∈ K`, copy at each `j ∈ J` (this is the
  partial-constant family — certificate: equal source/target words of the diagonal
  copy arcs; the same construction pattern as `constCircuit` in `ConstantMaps.lean`);
* `B_layer`: copy at each `j ∈ J`, and every `i ∈ K` in the cyclic gap after `j`
  reads `j` (adjacent fan-fill; certificate: source-major word = target-major word —
  each source's fan covers a consecutive target block, blocks in source order
  concatenate to the full target order).

Define `Φ(f) := A_layer * f * B_layer` (TIME order: first clamp, then `f`, then
fill).  Prove:

1. `Φ` is multiplicative on the local group: `Φ(f) * Φ(g) = Φ(f*g)` — the middle
   `B_layer * A_layer` acts as the identity on `X` (members of `X` have `K`-coords
   `κ`), and `runTrans (g * A_layer)` lands in `X` because `g = g*e` forces
   `Im ⊆ X`... careful with op-order; state everything through `runTrans`.
2. `Φ` is injective on the local group (recover `f` on `X` from `J`-coordinates;
   then `f = e*f` extends to everything).
3. `Φ(f)` FIXES `⊥` and `⊤`: `runTrans (A_layer) ⊥ = (⊥_J, κ_K)`, and
   `e`-collapse sends it to `min X`, whose `J`-coordinates are all `false` (each
   `j ∈ J` takes value `false` somewhere on `X`, and `min X` is below that), so the
   fill produces `⊥`; dually for `⊤`.  (This min/max argument is the verified repair
   of a gap in the paper draft — do not skip it.)
4. `Φ(f)` has no constant output coordinate (if a `J`-output of `f∘A` were constant,
   `f = f∘e` would make that coordinate of `f` constant, contradicting `j ∈ J`;
   `K`-outputs of `B_layer` copy `J`-outputs).
5. **Word-wise constant propagation** (`ConstantPropagation.lean`, the last hard
   piece): every element of `NonCrossing w` whose underlying map has no constant
   output coordinate and which fixes `⊥` and `⊤` ... is NOT the right statement;
   the correct one is constructive: for every certified layer `g` and every
   "input constancy pattern" `σ` (a partial map: some coordinates known constant),
   there is a CONSTANT-FREE certified layer `g'` and an output pattern `σ'` such that
   on inputs agreeing with `σ`, `g` and (`g'` overridden by `σ'`) agree, where `σ'`
   marks the outputs `g` forces constant.  (Per-layer surgery: a gate all of whose
   surviving predecessors are constant becomes a constant of `σ'`; an AND with an
   absorbing false constant predecessor becomes constant false; a neutral constant
   predecessor is dropped, possibly turning the gate into a one-arc COPY; deleting
   the same arc occurrences from the common word keeps it a common word, because a
   subsequence of a block-grouped word is block-grouped.)  Fold this over the word of
   `Φ(f)` starting from the empty pattern; because the END map has no constant output
   coordinate, the final pattern is empty, and the folded word of constant-free layers
   computes `Φ(f)` — i.e. `Φ(f) ∈ NonCrossingCF w`.  NO stacked certificate object is
   needed: the fold is over the `Submonoid.closure` word, layer by layer.
6. Conclude: `Φ(a), Φ(b)` lie in a local group of `NonCrossingCF w` (identity
   `Φ(e)`; the equations transport through multiplicativity), so they commute by 6d;
   pull back through injectivity: `a*b = b*a`.
